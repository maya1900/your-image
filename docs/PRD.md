# Your Image — 产品需求文档 (PRD)

> 一个基于智谱 CogView 的本地 AI 文生图工作台。
> 文档版本：v2.0 ｜ 2026-05-22

---

## 1. 产品定位

**Your Image** 是一款单机即用、零后端依赖的 AI 文生图工具。
用户自带智谱开放平台 API Key（Bring Your Own Key），即可在浏览器中完成 **文本生成图像 + AI 优化提示词** 的完整闭环，所有作品保存在本机 IndexedDB 中，不上云、不登录。

**核心理念**：
- **专注**：只做一件事——把文字变成好图。
- **私有**：Key 与作品仅留本机，无服务端转发。
- **省心**：默认免费模型 `cogview-3-flash`，可一键升级到 `cogview-4`。

---

## 2. 目标用户

| 用户画像 | 核心诉求 |
|---|---|
| 内容创作者 / 自媒体 | 快速产出封面图、配图、表情包 |
| 设计师 | 灵感采集、风格探索 |
| 开发者 / 极客 | 自己有智谱 Key，想要可控的本地创作工具 |
| AI 爱好者 | 体验 CogView-4 的中文字生成、双语提示能力 |

---

## 3. 功能范围（v1.0）

| # | 功能 | 优先级 | API |
|---|---|---|---|
| F1 | **设置中心**（Key 管理 + 模型选择 + 连通性测试） | P0 | `/chat/completions` |
| F2 | **文生图**（CogView-3-Flash / CogView-4 / cogview-4-250304） | P0 | `/images/generations` |
| F3 | **优化提示词**（短句 → 详细 prompt） | P0 | `/chat/completions` GLM-4-Flash |
| F4 | **本地画廊**（生成记录浏览/下载/再生成/删除） | P0 | IndexedDB |
| F5 | **Prompt 风格预设库**（动漫/摄影/赛博朋克/3D 等一键套用） | P1 | 内置 JSON |
| F6 | **批量生成**（1 / 2 / 4 张并发） | P1 | 客户端并发 |
| F7 | **Prompt 历史记录**（最近 50 条，可复用） | P1 | localStorage |

> 明确**不做**：图生图、抠图、Inpaint、Outpaint、指令式编辑——智谱 BigModel 平台目前没有原生 API 支持。这些功能后续若智谱推出原生 API 再迭代。

## 4. 详细需求

### F1 设置中心

**入口**：右上角齿轮图标 / 侧栏底部"设置"。

**字段**：
- **API Key**（密码框，保存到 localStorage `your-image:apiKey`）
- **默认图像模型**：下拉
  - `glm-image`（智谱图像系列）
  - `cogview-3-flash`（默认，免费）
  - `cogview-4`
  - `cogview-4-250304`
- **优化提示词模型**：下拉
  - `glm-4-flash`（默认，免费）
  - `glm-4-plus`
- **连通性测试**按钮：以 1 token 调用 `glm-4-flash` 测试 Key 是否有效
- **数据管理**：
  - 导出所有作品为 ZIP / JSON
  - 清空所有作品
  - 一键清除所有本地数据（含 Key）

**交互**：
- 未设置 Key 时，首页显示引导卡片"先配置 API Key →"。
- Key 测试成功后顶栏显示绿点 + "已连通"。

### F2 文生图

**布局**：左侧参数面板（固定 360px），右侧结果区（自适应）。

**参数面板**：
- Prompt 多行文本框（自适应高度，最长 1500 字）
- ✨ "优化提示词" 按钮（详见 F3）
- 反向提示词（折叠面板，默认隐藏）
- 风格预设按钮组（详见 F5）
- 尺寸选择器：
  - 1:1  1024×1024
  - 4:3  1152×864
  - 3:4  864×1152
  - 16:9 1344×768
  - 9:16 768×1344
  - 21:9 1440×720
  - 9:21 720×1440
  - 自定义（512–2048，16 整除）
- 质量：`standard` / `hd`（仅 cogview-4 系列可选）
- 数量：1 / 2 / 4
- 模型切换（覆盖默认）
- 主操作按钮："生成图像"（loading 时变 "生成中…N/M"，并提供"取消"）

**结果区**：
- 网格 1×1 / 2×2，每张图卡片：
  - 缩略图
  - 悬停：下载、复制 prompt、加入收藏、删除
  - 点击：lightbox 大图
- 失败卡片：红色错误条 + "重试"按钮
- 空状态：插画 + "在左侧输入描述开始创作"

### F3 优化提示词

**触发**：Prompt 输入框右上角的 ✨ 按钮。

**交互**：
1. 用户输入短描述（如"一只戴帽子的猫"）
2. 点击 ✨ → 按钮变 loading
3. 调用 GLM-4-Flash，prompt 替换为优化后的内容
4. 输入框上方显示一条提示："已为你优化提示词 · [撤销]"（保留原文，可点回）

**系统提示词**（写死在代码里）：
> 你是一名顶级 AI 绘图提示词专家。把用户的简短描述扩展为详细丰富的中文 prompt，包含：
> 1. 主体细节（外貌/服饰/动作）
> 2. 场景/环境
> 3. 光照与色调
> 4. 镜头/构图（如俯拍/特写/广角）
> 5. 艺术风格（如赛博朋克/油画/3D）
> 6. 画质关键词（如 8k, ultra detailed, masterpiece）
> 仅输出最终 prompt，不要解释。

### F4 本地画廊

**入口**：左侧栏"画廊"标签。

**视图**：
- 瀑布流 / 网格切换
- 按生成时间倒序
- 顶部筛选：全部 / 收藏
- 每张图卡片：
  - 缩略图
  - prompt 摘要（截断 2 行）
  - 模型 + 尺寸 + 时间
  - 操作：下载、再生成（带 prompt 跳回文生图）、复制 prompt、收藏、删除

**存储**：IndexedDB `your-image-db.creations`
**容量提示**：超过 100 张时画廊顶部出现"已存 N 张，建议定期导出 / 清理"。

### F5 Prompt 风格预设库

**预设**（v1 内置 12 个）：
- 国风水墨 · 动漫日漫 · 赛博朋克 · 3D Pixar · 油画肖像
- 极简扁平 · 复古胶片 · 蒸汽朋克 · 像素艺术 · 写实摄影
- 概念设计 · 韩漫插画

**用法**：用户输入主体后，点击风格按钮，自动在 prompt 末尾追加风格关键词。预设可叠加（同时勾选多个），用 chip 显示已选风格，可点击移除。

### F6 批量生成

**实现**：
- 在数量选择 1/2/4 之外，没有额外的"批量"概念
- 并发使用 `Promise.allSettled`，每张图独立成卡片
- 失败的图显示重试按钮，不影响其它图

### F7 Prompt 历史

- 顶部 Prompt 框下方提供"最近使用"chip 行，最多展示 5 个
- 点击 chip 直接填入 prompt
- 设置页可"清除 prompt 历史"
- 存储：localStorage `your-image:prompt-history`，最多 50 条

## 5. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 首屏 < 2s，画廊 100 张滚动流畅（缩略图懒加载） |
| 兼容性 | Chrome 90+ / Safari 15+ / Edge 90+ |
| 安全 | API Key 仅 localStorage，提供"一键清除"。CSP 限制只能连智谱域名 |
| 可访问性 | 暗色主题对比度 ≥ 4.5:1，主操作可键盘触发 |
| 国际化 | v1 仅中文 |
| 离线 | 不支持（必须联网） |

---

## 6. 数据与隐私

- 所有 API 调用从浏览器**直连** `open.bigmodel.cn`
- 生成结果通过 `aigc-files.bigmodel.cn` 返回，30 天有效；客户端**立即下载为 Blob 入库**，不依赖远程 URL
- IndexedDB 永不外传
- 不收集任何用户行为数据

---

## 7. 成功标准

- 完整跑通"输入 → 优化 → 生成 → 入库"
- 切换模型 / 尺寸无需刷新
- 失败请求有明确错误文案（401/403/429 区分）
- 画廊 100 张以内滚动 ≥ 50fps

---

## 8. 风险与缓解

| 风险 | 缓解措施 |
|---|---|
| API Key 在 localStorage 不安全 | UI 明确告知 "Key 仅存本机"；提供一键清除；建议不要在公共电脑使用 |
| 生成图 URL 30 天过期 | 拿到后立即 fetch 为 Blob 持久化，URL 只作中转 |
| Quota 用尽 / 限流 | 错误码 429 给出文案 + 智谱官网链接 |
| 浏览器关闭后任务丢失 | 请求最长 60s，不支持后台续跑（v1 限制） |

## 9. 后续路线（v2+，本次不做）

- 待智谱开放 image-to-image / inpaint API 后补齐
- 多模型对比生成（同 prompt 多模型并排）
- 自定义风格预设并云端分享
- 视频生成（CogVideoX）
